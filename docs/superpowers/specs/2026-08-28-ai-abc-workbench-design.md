# AI ABC 学员自助分析工具设计

## 目标

把现有关键词规则网页升级为面向学员本人使用的 AI 辅助 ABC 分析工具。学员粘贴自己的经历或逐字稿，系统识别 A（起因）、B（行为）和 C（结果），学员核对、修订后在本地导出。

工具输出属于观察草稿，不构成心理、医疗或其他专业诊断。

## 已确认范围

- 使用 DeepSeek API 进行上下文分析。
- 由项目方统一提供 DeepSeek API Key。
- API Key 仅存放在 Cloudflare Worker 的加密变量中。
- 前端继续部署在 GitHub Pages。
- Cloudflare Worker 负责 API 转发、输入校验、限流和输出校验。
- 服务端不保存原始文本、分析结果或学员身份信息。
- AI 不可用时回退到现有浏览器本地规则分析。
- 第一版不建设登录、数据库、历史记录和后台管理系统。

## 页面定位与文案

- 页面名称改为“学员自助 ABC 分析工具”。
- 删除课程期次字段。
- 姓名字段可选，建议填写昵称；未填写时使用“匿名学员”。
- 示例全部使用匿名角色，不出现真实学员姓名。
- 提交前提示文本将发送至 DeepSeek 分析，并要求学员主动勾选同意。
- 页面明确说明系统不保存资料，但第三方模型服务会收到本次分析文本。

## 页面结构

桌面端采用双栏工作台：左侧填写资料，右侧显示分析状态和结果。移动端自动变为单栏，分析完成后滚动到结果区域。

输入区包含：

- 可选昵称；
- 可选日期；
- 逐字稿或经历文本；
- 匿名示例按钮；
- 隐私确认勾选框；
- 开始分析、重新分析和清空操作。

结果区包含：

- 分析模式标记：AI 分析或基础规则分析；
- 候选场景数量和生成时间；
- 每个场景的 A、B、C；
- 原文定位、原文摘录、证据等级和风险标记；
- 编辑、取消和保存；
- JSON、CSV 和可读文本导出。

## 视觉设计

使用温和、可信、低压力的学习工具风格。主色为深绿，辅助色为米白与陶土色。A、B、C 使用不同但克制的颜色区分。

结果使用“观察草稿”“请核对是否符合真实经历”等表述，避免诊断感和评判感。没有结果时不显示无效导出按钮。风险提示只在命中风险时强化。

## AI 请求流程

1. 浏览器检查文本、隐私确认和长度。
2. 浏览器向 Cloudflare Worker 发送日期、匿名标识和文本。
3. Worker 校验来源、请求方法、内容类型、文本长度和频率。
4. Worker 将固定 ABC 标准和用户文本发送给 DeepSeek。
5. DeepSeek 只返回约定 JSON。
6. Worker 解析并校验 JSON，删除或拒绝不符合结构的输出。
7. 浏览器渲染场景，允许学员修订 A、B、C。
8. 导出功能使用学员修订后的数据。
9. 请求处理完成后，Worker 不持久化输入或输出。

## 输出结构

每个场景至少包含：

- `title`：匿名场景标题；
- `a`：起因；
- `b`：可观察行为；
- `c`：后续结果；
- `sourceQuote`：直接原文；
- `sourceLocation`：时间戳或“无时间戳”；
- `evidenceLevel`：高、中或低；
- `riskType`：无、离家、自伤/轻生、暴力或安全待确认；
- `limitations`：证据不足和不可推断内容。

AI 不得补写原文中不存在的行为、情绪、动机、时间坐标或结果。缺少信息时使用“待补充”，不得强行拼成完整循环。

## 学员修订

A、B、C 可原地编辑。原文摘录和原文定位保持只读。学员保存修改后，场景标记为“学员已修订”，导出内容采用修订版本并保留分析模式标记。

## 风险处理

离家、自伤、轻生、暴力和无法确认安全必须独立标记。页面提示学员联系可信任的成年人、当地紧急服务或专业支持，但不提供诊断或替代紧急援助。

## 安全与费用控制

- DeepSeek Key 使用 Worker Secret 保存，不出现在前端、日志和 GitHub。
- Worker 只允许配置的 GitHub Pages 来源访问。
- 仅接受 `POST` 和 JSON。
- 单次文本上限默认 20,000 个中文字符。
- 同一 IP 默认每小时最多 5 次，可后续调整。
- 对重复点击、超时、DeepSeek 非成功响应和非法 JSON 返回统一错误。
- 日志不得记录请求正文、模型完整响应或 API Key。

## 失败与回退

AI 超时、余额不足、限流、网络异常或格式校验失败时，前端明确说明本次 AI 分析未完成，并允许使用现有本地规则分析。回退结果必须标记“基础分析”，不能伪装成 AI 输出。

## 验收标准

- 页面没有课程期次和真实姓名示例。
- 桌面双栏、手机单栏均可用。
- 未勾选隐私确认时不能发送 AI 请求。
- API Key 不存在于网页源码、仓库或浏览器网络响应中。
- 正常文本、多个场景、无时间戳、信息不足和风险内容均能得到符合结构的结果。
- 超长输入、重复点击、接口超时、余额不足和非法 JSON 有明确反馈。
- A、B、C 可编辑，原文只读，导出使用修订结果。
- AI 失败时可以回退并正确标识基础分析。
- Worker 不保存学员原文和分析结果。
